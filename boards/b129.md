# B129: CANnify Micro HV Pico-Lock (STM32G0B1CETxN, 1 CAN channel)

Revision **B129A** (the only revision so far) is a HIL test board. Chip feature: `g0`. It is the only test board with an **FDCAN-lite core
and a real transceiver**, so it covers G0 on a real bus. Extracted with `tools/netlist.py` from:

| Rev   | Netlist (local, not in repo)                                                       | Schematic date | Exported   |
| ----- | ---------------------------------------------------------------------------------- | -------------- | ---------- |
| B129A | `cannify_micro.net` (`hw/b129_cannify_micro/source/b129a/cannify_micro.kicad_sch`) | 24 Dec 2023    | 2026-10-01 |

## CAN

| Function            | MCU pin          | Net        | Notes                                                                                                                                                                                                                                                          |
| ------------------- | ---------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FDCAN1 TX           | **PD1** (pin 39) | `FDCAN_TX` | AF3 → TCAN1044V TXD                                                                                                                                                                                                                                            |
| FDCAN1 RX           | **PB8** (pin 47) | `FDCAN_RX` | AF3 ← TCAN1044V RXD                                                                                                                                                                                                                                            |
| Transceiver standby | **PC13** (pin 1) | `CAN_STBY` | → TCAN1044V STB. No external resistor on the board. STB high = standby (as I recall, the TCAN1044V datasheet gives STB an internal pull-up; check this), so **drive PC13 low for normal mode**. Leaving it floating or high leaves the transceiver in standby. |
| Bus voltage sense   | PB10 (pin 22)    | `CAN_VDIV` | ADC, 39k2 / 1k69 divider (÷ 24.2) of +VIN_CAN                                                                                                                                                                                                                  |

- Transceiver: **TCAN1044V** (CAN FD, **not isolated**; VCC 5 V, VIO 3.3 V). ESD protection PESD2CANFD24V.
- Connectors: two Pico-Lock 4-pin (J4, J5), wired in parallel for daisy-chaining: **1 V+ (VCAN), 2 CAN_H,
  3 CAN_L, 4 GND**.
- **No termination resistor on the board.** The bus has to be terminated externally (or by a B125/B135 with its
  relay on).
- The board can be powered from the bus V+ (fuse, 56 V TVS, LV14360 buck, so "HV") or from USB-C.

FDCAN2 pins on the G0B1 (all AF3): TX PB1, PB6, PB13 / RX PB0, PB5, PB12. Several of these are on the headers

[nucleo.md](nucleo.md#single-wire-can-without-transceivers)) or an external transceiver.

## HIL notes

- One transceiver channel on FDCAN1. It can join the B125 / B135 bus with a Pico-Lock ↔ DE-9 adapter
  (CAN_H, CAN_L, GND). Mixed-family tests (G0 lite ↔ H7 full M_CAN) go here.
- No terminator: make sure the bus is terminated somewhere, e.g. by the relay on a B125/B135.
- Every test must drive `CAN_STBY` (PC13) low before expecting traffic. A test that leaves it high checks
  "transceiver in standby → no ACK" error handling.
- FDCAN2 can be exercised on the same MCU via the header pins (single wire, or an external transceiver).
